# 副业风向标 · 运营答案书

平台运营问题与解决方案案例库。当前版本：2026-09-27，300 条案例，138 篇来源分享，19 个平台/渠道。

## 使用

网站为静态 HTML、CSS 和 JavaScript，无需安装依赖或构建。可直接打开 `dist/index.html` 查看，或安装 Node.js 后在仓库目录运行 `node preview.mjs`，访问 http://127.0.0.1:4317 。

部署时将 `dist` 设为静态网站发布目录。推送到 GitHub 本身不等于启用 GitHub Pages。

## 更新内容

- `dist/data.js`：案例正文、来源链接、日期、结果及适用边界。
- `dist/highlights.js`：每条案例的突出结果，与案例顺序一一对应。
- `dist/guides.js`：详情解读，与案例顺序一一对应。
- `dist/catalog-summary.js`：汇总数据。
- `dist/index.html`：网站首页及固定统计文案。
- `dist/app.js`：平台筛选、搜索、详情、每页 10/30/50 条分页。
- `dist/style.css`、`dist/refined.css`、`dist/compact.css`：页面样式。
- `dist/logos/` 及图片文件：网站使用的资源。

新增案例时同步更新三组数据的对应关系、汇总和首页数量。保留原文链接；所有结果为作者或当事人自述，并非收益保证。

体验卡位于当前页案例之后，分页位于体验卡之后。详情页同样保留领取入口。

本仓库包含可独立部署的完整前端，不包含账户凭据、OAuth 数据或原始抓取资料。平台标识和社区内容的权利归相应权利人所有。
